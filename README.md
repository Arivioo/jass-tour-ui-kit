# Beize Jass Tour

A Jass card game scoring application built with React, TypeScript, and Supabase.

## Tech Stack

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS
- Supabase

## Development

```sh
npm install
npm run dev
```

## Deployment

Pushes to `main` automatically build and deploy to the web server via GitHub Actions.
